# Mijn geld

Een eenvoudige local-first webapp voor persoonlijke financiën, gebouwd met React, TypeScript en Vite.

## Functies
- Rekeningen en saldi
- Inkomsten, uitgaven en overboekingen
- Spaardoelen
- Dashboard
- JSON-back-up import/export
- Opslag in localStorage

## GitHub Pages
Upload alle bestanden naar een repository. Gebruik bij voorkeur GitHub Actions voor de Vite-build en publicatie. `vite.config.ts` gebruikt een relatieve base (`./`) zodat de build ook onder een repositorypad werkt.

## Lokaal ontwikkelen
```bash
npm install
npm run dev
```
